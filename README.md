# PipeTube — YouTube в Lampa / ByLampa через Piped

Плагин добавляет в левое меню пункт **YouTube**. Видео, поиск и каналы идут через публичные инстансы Piped: поток проксируется сервером инстанса, а не грузится с googlevideo.com.

## Возможности

- Список инстансов берётся с `piped-instances.kavin.rocks` плюс встроенный запасной список. Каждый инстанс проверяется: запрос к API и к прокси видео. Лучший выбирается автоматически.
- Ручной выбор инстанса и свой URL API: Настройки → PipeTube → Инстанс Piped, или кнопка на главной.
- Если текущий инстанс падает (бот-проверка YouTube, 5xx, таймаут), плагин переключается на следующий. В ручном режиме переключения нет.
- Главная: рекомендации по истории просмотров, новое в подписках, тренды.
- Поиск, страница канала с подпиской, список подписок, история.
- Плеер Lampa: HLS (до 1080p) или MP4 360p, субтитры, продолжение с места остановки.
- SponsorBlock: пропуск спонсорских вставок, опционально ещё заставок, концовок и самопиара.
- Долгое нажатие на видео открывает меню: MP4-режим, переход на канал, подписка.

## Установка

1. Загрузить `ptube.js` в репозиторий на GitHub и включить GitHub Pages (или положить на свой nginx).
2. В Lampa: Настройки → Расширения → Добавить плагин → `https://<user>.github.io/<repo>/ptube.js`.

Без шага ниже всё работает, кроме импорта подписок из Google. Подписываться на каналы можно и локально, прямо в плагине.

## Импорт подписок из Google (опционально)

Нужен отдельный проект Google Cloud.

1. console.cloud.google.com → новый проект → APIs & Services → включить **YouTube Data API v3**.
2. Google Auth Platform:
   - **Branding**: название, email, ссылки на домашнюю страницу и политику конфиденциальности (GitHub Pages).
   - **Audience**: External, статус **In production**. В режиме Testing refresh-токен живёт 7 дней.
   - **Data access**: scope `https://www.googleapis.com/auth/youtube.readonly`.
   - **Clients → Create client**: тип **TVs and Limited Input devices**.
3. Вписать `Client ID` и `Client secret` в начало `ptube.js` (`CFG.GOOGLE_CLIENT_ID`, `CFG.GOOGLE_CLIENT_SECRET`).
4. В Lampa: Настройки → PipeTube → Подписки из Google → ввести код на google.com/device.

`youtube.readonly` — sensitive scope. Без верификации приложения Google при входе покажет экран «приложение не проверено». Его можно пройти через «Дополнительно → Перейти». Для личного использования этого достаточно.

Подписки обновляются раз в сутки. Если отписаться от импортированного канала в плагине, он не вернётся при следующем импорте. После выхода из Google подписки остаются локально.

## Ограничения

- Рекомендации не настоящие: официальный API YouTube их не отдаёт. Плагин строит их из похожих видео к последним просмотренным, свежего из подписок и трендов. Пока история пуста, раздел заполняется лентой и трендами.
- Тренды на части инстансов могут быть пустыми: это зависит от YouTube.
- HLS отдают не все инстансы и не для всех видео. Тогда играет MP4 360p. Если HLS не воспроизводится на устройстве, в настройках можно выбрать MP4.
- Публичных инстансов Piped мало, и их периодически блокирует YouTube. Если видео не открывается, нажми «Перепроверить все» в меню инстансов.

## Хранение данных

Всё хранится в `localStorage` устройства с ключами `ptube_*`: подписки, история, кэш инстансов, токен Google.
